# Words 背单词 App

完全本地运行、轻量级、无数据库的 Android 背单词应用。

##  功能特性

- ** 完全本地词库**：读取本地 `assets/result.json`，无需联网。
- **🃏 记背模式 (Study)**：
  - 每次展示 10 个单词，按 JSON 原顺序排列（含单词、词性、中文释义）。
  - **左滑标记**：向左滑动单词可标记为“已记住”，系统会自动按顺序增补 1 个新单词，保持 10 个待背词的状态。
- ** 复习模式 (Memorized)**：
  - 展示所有“已记住”的单词，随时可以回顾。
  - **左滑重记**：向左滑动已记住的单词，可将其移出记忆库，重新回到“记背模式”的队列中。
- ** 词典模式 (All Words)**：
  - 按英文字典规范进行 A-Z 首字母排序。
  - **中英文搜索**：顶部设有搜索框，支持输入英文单词或中文释义进行模糊搜索。
  - **A-Z 快速索引**：右侧竖栏设有 A-Z 索引，支持点击或滑动快速跳转到对应首字母的单词位置。
- ** 进度统计**：在“记背”和“已记住”页面顶部，实时显示 `已记住/总数 (百分比)`学习进度。
